# Titanic Data Cleaning and Visualization Project

## Project Overview
This project is an internship assignment dedicated to comprehensive **data cleaning, data quality assessment, and exploratory data visualization** on the classic Titanic passenger dataset.

> **Note:** This project is strictly focused on data cleaning and exploratory data visualization. It does not implement machine learning models, web applications, or synthetic data.

## Project Objective
The primary objectives of this project are:
1. Conduct an in-depth audit of data quality (missing values, formatting inconsistencies, duplicates, and outliers).
2. Develop and document an appropriate data cleaning and preprocessing strategy.
3. Produce clean, structured, and validated datasets for downstream analysis.
4. Perform exploratory data analysis (EDA) and visualize key demographic and survival patterns.

## Dataset Source
- **Dataset:** Titanic - Machine Learning from Disaster (`train.csv`)
- **Source:** Kaggle / Titanic passenger manifest data
- **Location in Repository:** `data/raw/train.csv`
- **Processed Data Output:** `data/processed/`

## Tools and Libraries
The project utilizes the Python data science stack:
- **Pandas:** Data manipulation, cleaning, and inspection
- **NumPy:** Numerical and vectorized calculations
- **Matplotlib:** Base charting and graphic customizations
- **Seaborn:** Statistical data visualizations
- **Jupyter Notebook:** Interactive environment for documentation and iterative analysis
